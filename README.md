# Pixel Adventure: Sukuna Update

Game platformer pixel untuk browser HP dan PC.

## Fitur
- Musuh slime dan naga dengan health bar.
- Tombol HIT untuk menebas musuh yang dekat.
- FUGA: panah api yang meledak saat mengenai musuh dan memberi damage area.
- DOMAIN EXPANSION: jurus ultimate yang baru bisa digunakan saat meter mencapai 100%.
- Koin menambah meter ultimate.
- Bendera finish, 3 nyawa, dan tombol ulang.

## Kontrol
- PC: A/D atau panah untuk bergerak, Space untuk lompat, J = HIT, K = FUGA, L = DOMAIN.
- HP: gunakan tombol di layar.

## Mainkan
Buka `index.html` di browser.

## Upload ke GitHub Pages
1. Buat repository baru bernama `pixel-adventure`.
2. Upload `index.html` dan `README.md`.
3. Buka Settings → Pages.
4. Pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.
